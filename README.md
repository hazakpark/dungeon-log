# 던전 로그

하루를 던전으로 다루는 텍스트 어드벤처식 습관 기록 웹앱.
3막 구조: 입장(아침) → 탐험(낮) → 귀환(밤).

## 확정된 규칙

- **하루 경계**: 새벽 4시. 밤 3시 59분에 체크해도 어제로 기록된다.
- **완료 판정**: 퀘스트별로 `체크` 또는 `타이머` 선택. 타이머는 앱을 닫아도 이어진다.
- **실패 처리**: 스트릭은 *연속 입장* 기준. 부분 탐험도 스트릭이 끊기지 않는다.
  *연속 완주*는 별도 지표로 따로 표시된다.
- **복귀 보상**: 하루 이상 빠졌다 돌아오면 「재정비의 증표」 + 그날 EXP 1.5배.
- **드랍**: 완주 시 EXP는 항상, 증표는 확률(35%, 연속 완주 시 최대 50%).
  「몰입의 결정」은 5% 고정. 추첨은 하루에 한 번뿐이라 되돌렸다 다시 깨도 다시 굴리지 않는다.
- **명언 없음**: 대신 몇 년 전 오늘의 자기 한줄평(없으면 180/90/30/14/7/1일 전)과 누적 통계를 보여준다.

## 실행

가장 간단한 방법은 `index.html`을 브라우저로 여는 것. 기록은 localStorage에 남는다.

홈 화면 아이콘으로 쓰려면 HTTPS 호스팅이 필요하다.

### GitHub Pages
1. 새 저장소를 만들고 이 폴더의 파일 전부를 올린다
2. Settings → Pages → Source: `main` 브랜치 루트
3. 발급된 주소를 폰 브라우저에서 열고 "홈 화면에 추가"

### Netlify (더 빠름)
app.netlify.com/drop 에 이 폴더를 통째로 끌어다 놓으면 즉시 주소가 나온다.

## 기록 백업 — 반드시 설정할 것

기본 상태의 기록은 **이 기기 브라우저 안에만** 있다.
폰을 바꾸거나 브라우저 데이터를 지우면 그대로 사라진다.
아래를 설정하면 기록이 매일 자동으로 GitHub 비공개 저장소에 남는다.

### 1. 데이터용 저장소 만들기

앱을 올린 저장소와 **별개로** 하나 더 만든다. 반드시 **Private**로.

이름은 아무거나. 예: `dungeon-log-data`

### 2. 토큰 발급

GitHub → Settings → Developer settings → Personal access tokens →
**Fine-grained tokens** → Generate new token

| 항목 | 값 |
|---|---|
| Repository access | Only select repositories → 방금 만든 데이터 저장소 |
| Permissions → Repository permissions → **Contents** | **Read and write** |
| Expiration | 최대 366일 (만료되면 앱이 경고한다) |

Contents 외에 다른 권한은 주지 않는다. 토큰이 새어도 그 저장소 하나로 피해가 끝난다.

발급 직후 화면에 한 번만 보이니 그 자리에서 복사한다.

### 3. 앱에 연결

설정 탭 → `── 저장소 연결 ──`

- 저장소: `사용자명/dungeon-log-data`
- 토큰: 복사한 값 붙여넣기
- `연결` 누르기

상태가 `백업됨`으로 바뀌면 끝이다. 이후로는 알아서 올라간다.

### 무엇이 저장되는가

```
data.json          앱이 읽고 쓰는 상태 전체. 복원할 때 쓰인다.
journal/2026.md    사람이 읽는 사본. 연도별.
```

`journal/2026.md`는 **앱 없이 그냥 읽으라고 있는 파일**이다.
github.com에서 바로 열리고, 몇 년 뒤 이 앱이 안 돌아가도 텍스트 편집기로 읽힌다.

푸시할 때마다 커밋이 남으므로 저장소의 커밋 목록이 곧 기록의 변경 이력이 된다.

### 새 기기에서 복원하기

폰을 바꿨거나 브라우저 데이터를 지웠을 때:

1. 앱 주소를 연다
2. 설정 탭 → 저장소 연결에 **같은 저장소 경로와 토큰**을 넣는다
3. `저장소에서 복원`을 누른다

기록 전체가 돌아온다. (이 버튼은 현재 기기의 기록을 저장소 것으로 **덮어쓴다**.)

### 백업이 멈추면

조용히 실패하는 게 제일 위험하므로 앱이 계속 알린다.

- 상태창 오른쪽에 `백업됨` / `백업 N일 전` / `백업 실패`
- 3일 넘게 안 올라가면 던전 탭에 경고
- 7일 넘거나 오류가 나면 귀환 화면에서 내보내기를 권한다

토큰 만료가 가장 흔한 원인이다. 새로 발급해서 설정에서 다시 넣으면 된다.

## 데이터

- 로컬: 브라우저 localStorage (`dungeon-log-v1` 키)
- 토큰: 별도 키(`dungeon-log-token`)에 저장된다. **`내보내기` 파일에는 포함되지 않는다**
- 수동 백업: 설정 탭의 `내보내기`로 JSON을 받고, `가져오기`로 복원한다

## 파일

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체 (HTML/CSS/JS 단일 파일) |
| `manifest.json` | PWA 설치 정보 |
| `sw.js` | 오프라인 캐시 (배포 시 `CACHE` 버전을 손으로 올릴 것) |
| `icon-192/512/180.png` | 아이콘 |
